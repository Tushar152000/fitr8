# Protein for Indian vegetarians

A ready-to-publish FITR8 Blog post. Import it in the admin: **Blog → Posts → Import post**, select
every file in this folder (`post.json`, `article.html` and the images) and click **Import as draft**,
then review and **Publish**. Format: docs/BLOG.md "Importing a post".

- Sources: ICMR-NIN (2020, 2024), ISSN position stand (Jäger 2017), Morton 2018, Helms 2014. Protein
  per serving comes from the FITR8 starter food database.
- Photos: Wikimedia Commons, CC BY-SA 4.0 / CC BY 2.0. The credit lines in `article.html` are required
  by those licences; keep them. `social-card.png` is FITR8's own share image.
