## Auth (`src/lib/auth.tsx`, `token-store.ts`, `api.ts`)

- Bearer token in SecureStore key `fitlens.session` (localStorage on web preview). No refresh; server session slides (90 d idle).
- Any 401 with a token → `clear()`: RevenueCat logOut, drop token, `queryClient.clear()`, delete stored token + coach conversation id.
- Startup `readToken` → `/api/me`; 401 → signed out, any other failure → `status: "offline"` (`_layout.tsx` `OfflineStart`, "Try again" → `retry()`). `clear()` also cancels water reminders.
- Google: PKCE → `openAuthSessionAsync(${API_URL}/api/auth/mobile/start?challenge&redirect=Linking.createURL("auth"))` → `POST /api/auth/mobile/token`. Production API rejects `exp://`, so Google fails in Expo Go against prod.
- Apple (iOS only, if `isAvailableAsync()` and `providers.apple`): raw nonce → sha256 to Apple → `POST /api/auth/apple`.
- Dev login if `providers.dev`.

## API client

`src/lib/config.ts`: `EXPO_PUBLIC_API_URL` default `https://api.fitr8.com` (the Nest API directly; eas.json same). Local: no `apps/mobile/.env`; `scripts/local.mjs` `mobileApiUrl` passes `EXPO_PUBLIC_API_URL` (root `.env` value, else `http://<LAN-IP>:<API port>`) to Expo's process env (unset would mean production). `api()` → `ApiError(0, OFFLINE)` on network failure. `apiStream` uses `expo/fetch` for coach SSE. React Query (`query.ts`): staleTime 30 s, no retry on 4xx, NetInfo online manager. Shared keys (`queries.ts`): day=`/api/dashboard`, workout=`/api/workouts/today`, water, billing, `planQuery` (`/api/plan`, used by Profile, onboarding, welcome back, workout locked). `errorMessage(e, fallback)` (`lib/api.ts`) is the one error-text helper. Calendar labels for API dates: `lib/dates.ts` (UTC, cached `Intl` formatters; accepts YYYY-MM-DD or full ISO). Photos compressed to 1024 px JPEG before upload.
